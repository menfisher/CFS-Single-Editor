Overview

ContactsFreeShare is a local desktop web app for maintaining a shared contact directory, creating MeetingData layouts, designing Field Lists, and producing printable Address Book PDFs. It runs in a browser at http://127.0.0.1:8000, but its data and files live on the computer running the app.

The app can work locally, or it can connect to Google for contacts, Google Drive backups, App Revisions, shared settings, and multi-editor workflows. When GoogleConnect is enabled, local changes can queue until the user chooses Upload.

Main Work Areas

  • Contacts: Add, edit, filter, move, message, email, delete, import, export, and back up contact records.
  • MeetingData: Create meeting sections and edit their printable visual layout.
  • Field List: Build and print field list templates using contact fields, meetings, phones, addresses, relationships, emails, and page numbers.
  • Address Book: Configure and generate an address book PDF, including cover, index, print order, field choices, and paper book output.
  • GoogleConnect: Sign in, control editor roles, import, upload, sync, and monitor Google/Drive state.
  • App Revisions: View revision notes, check for public app updates, and download update packages.

The Contacts page is the main directory. It shows contact names, fields, meetings, phones, and addresses. Click a row to open the contact detail page. Use checkboxes to select contacts for bulk actions.

  • Message text: The text sent separately to each selected phone number.
  • Phone list: Shows eligible selected phone numbers. Home, NH, and Work labels are skipped.

  • Close / Done: Closes the modal after sending or cancels before sending.

  • Subject: Subject line for the email.
  • Message: Email body text.
  • Email address list: Shows eligible email addresses for selected contacts.
  • Open Email: Opens the default email app with selected addresses in BCC.

Export And Backup Outputs

  • App CSV: A ContactsFreeShare-specific contacts CSV.
  • Google CSV: A contacts CSV intended for Google import compatibility.
  • vCard: A standard contact file format.
  • JSON backups: Full app backup files for Contacts or MeetingData.

Editing Roles, Sync, And Safety Notes

  • Local saving: The app always keeps local data on the current computer.
  • Google Contacts: Contact changes can be queued and uploaded to Google Contacts when Google saving is enabled.
  • Google Drive: Shared settings, MeetingData, Field List data, App Revisions, backups, and PDFs can use Drive storage.
  • NO-EDIT mode: In multi-editor mode, users cannot edit until an Editor signs in or a permitted access role is active.
  • Editor lock: Prevents multiple active editors from editing at the same time.
  • Pending uploads: Banners and Upload reminders show when local changes need to be sent to Google/Drive.
  • Messaging: macOS Messages automation can submit messages to Messages, but carrier/iMessage delivery is ultimately controlled by the paired phone and Apple services.

Publishing App Updates

Developer update publishing is handled by scripts in the project folder.

CommandWhat It Does
bash scripts/build_portable_app.shBuilds the portable app folder and Mac/Windows zip files in dist/. It also creates app_update_manifest.example.json.
scripts/publish_app_update.sh 1.2 "Release notes"Updates APP_VERSION, adds an App Revisions row, builds packages, creates app_update_manifest.json, removes older update zips by default, and pushes the current packages to the GitHub Pages update repo.
CONTACTSFREESHARE_KEEP_OLD_UPDATE_PACKAGES=1 ...Optional prefix that keeps older package zips instead of cleaning them.

Use straight quotes in Terminal around release notes. This matters when release notes contain characters such as &.
